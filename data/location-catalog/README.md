# Географический справочник

Данные GeoNames: https://www.geonames.org/. Лицензия — [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

`countries.json` содержит действующие страны и территории ISO, а также код XK из GeoNames. Устаревшие AN и CS исключены. Названия стран для русского интерфейса сформированы через `Intl.DisplayNames`.

Файлы `XX.json` содержат города из `cities15000.txt` одной страны. Сервер читает их по запросу, кеширует не более восьми стран и возвращает ограниченную поисковую выборку; данные не входят в начальный frontend bundle.

Русские названия городов России и Беларуси взяты из официальных alternate-names архивов GeoNames с языком `ru`; исторические, разговорные и завершившие действие названия исключены. Равнозначные противоречивые варианты не выбираются автоматически. Для остальных городов используется основное имя GeoNames. Альтернативные имена служат только для поиска: выбранный город всегда сохраняет основное актуальное название.

Происхождение, число записей и контрольные суммы — в `source.json` и `russian-names.json`. Генератор включён в репозиторий: `tools/scripts/build-location-catalog.mjs`. Из корня backend выполните `npm run catalog:build -- /absolute/path/to/geonames-sources`. Он использует `countryInfo.txt`, `cities15000.txt` и подготовленный `ru-city-names.json`. При отсутствии последнего используются сохранённые проверенные переводы из `russian-names.json`. Для обычного запуска API генератор и исходные таблицы не нужны.

Города, отсутствующие в справочнике, пользователь вводит вручную; координаты такого выбора остаются неизвестными (`null`).
